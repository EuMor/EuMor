### 👨‍🏫 About me

> A programming teacher who writes code beyond the whiteboard.

My goal is **versatile development** — I want to feel equally confident in **mobile**, **desktop**, and **web**.

Teaching has given me one key superpower: **breaking complex things down until they're crystal clear**.  
Now I bring that same clarity to my architecture, my code, and my commits.

- 🎓 **Teaching** — I explain programming to beginners, and it makes me a better engineer every day.
- 🧠 **Learning** — currently in deep focus on the Android ecosystem.
- 🎯 **Building** — turning theory into real, shipped products.
- 🤝 **Open to** — collaboration, code reviews, and open-source contributions.
